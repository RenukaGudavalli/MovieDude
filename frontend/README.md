# MovieDude Netflix-style frontend

React + Vite UI for the MovieDude recommendation API.

## Run

```bash
npm install
npm run dev
```

The backend should run on `http://127.0.0.1:8000`.

## Included shelves
- Telugu Movies
- Marvel & Spider-Man
- Love Stories
- Trending Now

Poster images are loaded automatically from public Wikipedia thumbnails when available. The recommendation results still come from the original MovieDude content-based filtering engine.
